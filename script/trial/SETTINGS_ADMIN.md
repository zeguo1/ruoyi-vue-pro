# 知办对接配置后台

入口：**系统管理 → 知办对接配置**，前端组件 `crm/trial/settings/index`。
该页面供运营租户管理员维护 MGS 开户服务。用户登录凭据、Agent 工具凭据和安全卡片凭据分别管理。

## 配置顺序

1. 在基础与开户中填写环境标识、运营租户内真实线索负责人编号、体验期限和容量、MGS 对外 HTTPS 地址及登录地址、已启用的 OAuth 客户端编号。租户边界取自部署配置，页面不能改为其他租户。
2. 在调用允许名单中填写知办实际助手 ID、audience 和 channel。issuer 在签发凭据后不可修改。
3. 在短信验证中绑定已有 `trial-mobile-verify` 模板，设置频率、有效期和次数。短信通道、供应商模板仍在短信管理中维护。
4. 在知办回调中填写知办 HTTPS 基础地址及其服务端约定的出站 HMAC 密钥编号、密钥。当前适配器追加 `/internal/mgs-trials/v1/lookup` 和 `/ensure`；页面保存不会证明这些远端接口存在。
5. 保持“开启新试用开户”和“开启标准连接器入口”关闭，先保存配置。首次保存自动生成缺失的验证码保护密钥和账号凭据加密密钥；已有密钥保留。出站签名密钥留空表示保留，仍有未结束申请时禁止更换出站密钥或编号。
6. 在服务凭据中分别签发 Agent 工具 Token（TOOLS）、安全卡片 Token（SMS_VERIFICATION、CONSENT），以及知办私有服务 HMAC（AUTHORIZATION、DELIVERY、EVENTS）。有效期 1–365 天；明文仅在签发响应中展示一次，读取配置不回显。Bearer Token 只存 SHA-256 摘要；HMAC 密钥存入加密配置。遗失时撤销并重新签发。
7. 按“知办填写项”设置知办连接器和知办后端。安全卡片/HMAC 凭据不能放进公开工具参数。完成 TLS、短信、安全卡片、用户确认、回调的独立联调后，再启用入口及开户。页面会校验必要参数和本地资料；本地检查通过不等于双系统联调成功。

填写 HTTPS 地址不会自动创建域名、配置证书、代理或打通网络。配置页面不发送短信，不创建客户、订单或试用账号，也不发布知办连接器。

## 权限与部署

- 应用 `V20260915_08__trial_settings.sql` 创建加密配置表及空初始版本，再应用 `V20260915_09__trial_settings_menu.sql` 添加三个菜单权限。
- `crm:trial-settings:query` 读取脱敏配置；`crm:trial-settings:update` 保存；`crm:trial-settings:secret` 签发/撤销服务凭据。
- 给运营租户的对应套餐、管理员角色追加这三个菜单 ID，保留已有菜单和权限。此次目标是运营租户 121 的 qiyunadmin；不要通过授予跨租户 super_admin 来解决入口不可见。
- 除权限外，服务端同时核对登录用户的真实租户、当前租户、用户类型和启用状态。切换请求头到运营租户不能绕过真实身份检查，服务 Bearer Token 不能调用管理 API。
- 管理 API `/admin-api/crm/trial-settings/*` 使用普通后台登录鉴权，禁止响应缓存并关闭请求内容审计；以 `@Hidden` 排除于 Agent OpenAPI。对外工具分组 `/v3/api-docs/trial-connector` 仍只有四个公开工具。

## 存储与生效

初始 revision=0 时从 `mgs.trial` 部署配置读取；第一次保存后，加密数据库配置成为运行配置。保存事务成功后原子替换当前实例快照，其他实例约 5 秒刷新，重启重新加载。通过 revision 检查拒绝覆盖他人的修改。已有申请继续使用自己的业务参数快照。

配置采用 AES-256-GCM，运营租户及版本参与完整性校验。主密钥默认位于 `/data/trial-settings/master.key`（0600），目录 0700。部署已将 `/data` 挂载到持久卷。多实例必须共享同一主密钥；可通过 `mgs.trial-settings.key-file` 指定挂载文件位置。

**备份必须同时覆盖数据库配置和对应的主密钥持久卷**，主密钥应独立保管，不能进入源码仓库。已有配置解密失败时不会自动生成替代密钥，服务关闭新开户与标准连接器入口；恢复正确配置及原密钥后自动重新加载。单独回退到不支持后台配置的旧 JAR 会使用旧 YAML 参数，不能将其视为无差别回滚。

## 回归范围

- `TrialSettingsHttpTest`：隔离 H2、实际 MVC/登录过滤器/权限拦截，验证加密落库、脱敏读取、重启恢复、并发版本、租户隔离、只读权限、嵌套参数、错误不落库、实际 Bearer 签发与撤销、启用前置条件、主密钥丢失关闭入口、活动申请期间禁止换签名密钥，以及数据库错误不回显秘密。
- `TrialServiceAuthTest`：新增私有 HMAC 到期拒绝，保留旧无到期时间凭据兼容。
- `script/trial/run-tests.sh`：已有开户、短信、授权、凭据交付及连接器回归。
- `script/openapi/run_integration_checks.sh`：实际生成的全量文档、引用及参数合同；验证管理 API 未进入 Agent 文档。
- 浏览器使用隔离响应覆盖管理员、只读账号及 390px 手机视口，验证保存、一次性凭据关闭清除、撤销和读取失败状态。真实服务只做读取验证，不签发生产凭据或创建真实业务数据。

OpenAPI 版本标识：`full-contract-v7.3`。此交付不表示知办已同步或完成联调。
